# 展翅翱翔 · 在线对局（Wingspan Online）

基于桌游《展翅翱翔》（Wingspan）官方规则的在线网页版，支持 **4–8 人**对战。
**全部卡牌使用官方扫描图与官方数值**（67 张基础版鸟卡 + 5 张 Swift-Start 官方教学卡 + 7 张奖励卡 + 16 块目标砖），零改动。

---

## 快速开始

前置：安装 [Node.js](https://nodejs.org) 18+（无需任何依赖包）。

```bash
# Windows 双击 start.bat，或：
node server/server.js
```

打开 <http://localhost:8420> 即可：

- **单机试玩**：立即与机器人开一局（可选 4/5/6/7/8 人）。
- **创建房间**：把 4 位房间码发给朋友，他们在首页输入即可加入；空位自动由机器人补齐。
- 8 人为**非官方扩展模式**（沿用官方 Flock 双组并发，4+4 分组），界面全程标注。

## 玩法速览

- 每局 4 轮，每轮行动数 8/7/6/5；四大行动：打出鸟类 / 获取食物 / 产蛋 / 抽取鸟卡。
- 打鸟支付：食物成本（支持「任意 2 食物 = 1 任意食物」，仅打鸟时可用）+ 列蛋成本 0/1/1/2/2。
- 能力五色：白（打出时）、棕（该行行动时从右到左）、粉（对手回合触发，回合间限 1 次）、青（轮末）、黄（终局）——本牌库以白/棕/粉为主。
- 轮末目标计分：绿面按名次（基础严格式平局 / Flock 友好式平局）；终局 = 鸟分 + 奖励分 + 目标分 + 蛋/储存/塞卡各 1 分，平局比剩余食物。
- 完整规则可在对局中点顶栏「📖 规则」；「🃏 卡牌」可浏览全部卡牌与能力中文释义。

## 模式对照

| 模式 | 人数 | 规则来源 | 并发 | 喂食器/托盘 |
|---|---|---|---|---|
| 基础 | 4–5 | 官方基础版 | 顺序回合 | 全桌共用 |
| Flock | 6–7 | 官方亚洲篇 | 每组 1 人同时行动 | A/B 组独立 |
| 扩展 | 8 | **非官方**（Flock 机制 4+4） | 同 Flock | A/B 组独立 |

## 工程结构

```
server/server.js      零依赖 Node 服务器：静态文件 + 自实现 WebSocket(RFC6455) + 房间 + 权威裁决
shared/engine.js      规则引擎（服务端与浏览器共用）：Setup/10留5、四大行动、喂食器、
                      效果原语解释器、粉色窗口、轮末目标（严格式/友好式平局）、终局计分、
                      4-8 人调度（顺序/Flock 波次）、不变量断言、信息隐藏视图
shared/bot.js         机器人策略（贪心：打鸟→产蛋→取食→抽卡）
client/               三段式布局客户端：顶栏 + 中央玩家面板(官方栖息地背景) + 侧栏(目标/玩家/日志)
                      + 底部手牌区；决策弹窗、粉色提示、8人聚焦、深浅主题
data/game_data.json   结构化卡牌数据（由 tools/build_data.mjs 生成）
assets/               官方素材（卡牌扫描、目标砖、栖息地背景）
tests/sim.mjs         无头回归：5 种人数模式 × 3 种子全量模拟 + 不变量断言
```

### 技术要点（对齐 02 技术文档）

- **服务端权威**：所有规则裁决只发生在服务端引擎；客户端仅渲染与提交意图。
- **信息隐藏**：视图按玩家投影，他人手牌/牌库顺序永不下发（`stateView`）。
- **生成器驱动的可暂停状态机**：人类决策点暂停、机器人同步作答；掉线玩家自动安全托管，重连按 pid 恢复座位。
- **确定性**：可注入双流 RNG（牌库/骰子），事件日志带修订号，单局可复现。
- **效果原语**：67 张卡能力全部映射为结构化 ops（`tools/build_data.mjs`），中文能力文本由同一映射确定性生成，保证「文案 = 实现」。

## 已知边界（v1）

- 玩家间「赠送资源」未实现（官方基础规则允许，后续可加双向确认交互）。
- 青色/黄色能力无对应卡（基础牌库本就不含，引擎已预留钩子）。
- 服务器重启会丢失进行中的房间（事件日志已可用于审计，完整重连恢复待做持久化）。
